# Savour

[English](README.en.md)

**Save now. Savour later.**

> 收藏從未停止，行動從未開始。

內容常常存得亂七八糟，四散在書籤、按讚、截圖裡，結果真的有空想閱讀時，又陷入尋找循環。於是做了 Savour 負責保存：點一下，把感興趣的內容存進自己的 Notion 資料庫，統一保存、方便管理，等有空再慢慢消化資訊。

## 支援

| 來源 | 保存內容 |
|---|---|
| 網頁文章 | 正文、可取得的圖片與文章排版 |
| 社群貼文 | 貼文內容、可取得的圖片與來源資訊 |
| YouTube | 影片嵌入、說明資訊與章節 |

目前支援的社群網站包括 Threads、噗浪、X、Instagram、Facebook 與 LinkedIn。

除了保存整篇內容，也可以只保存反白的段落，或將它加入現有的 Notion 頁面。

## 共通行為

- 只在你主動按下保存時讀取內容，資料由你的 Chrome 直接送到自己的 Notion，沒有中介伺服器。
- 社群貼文請先開啟該貼文頁面，再按保存。
- 同一篇內容會辨識是否已保存，避免重複建立頁面。
- 保存範圍依網站與當下載入的內容而異；作者、發布時間等資訊依來源可取得的資料填入。不自動收集留言與反應數，也不下載影片檔。

## 安裝

需要 Chrome 102 以上版本與 Notion 帳號。

Savour 即將上架 Chrome 線上應用程式商店。想先試用的話，可以手動載入：

1. 下載或 clone 這個 repo，放在不會被刪除的位置，資料夾被刪除後擴充功能也會消失。
2. 開啟 `chrome://extensions`，啟用「開發人員模式」，按「載入未封裝項目」，選擇含有 `manifest.json` 的資料夾。
3. 建議將 Savour 釘選在 Chrome 工具列，方便隨時保存。

手動載入的版本不會自動更新，更新時請重新下載並重新載入。

## 第一次設定

### 1. 連接 Notion

1. 到 [Notion Integrations](https://www.notion.so/profile/integrations) 建立 Internal Integration，開啟「讀取內容、插入內容、更新內容」權限。
2. 複製 Integration Token。
3. 開啟 Savour 設定頁，在「Notion 連線」貼上 Token，按「儲存設定」。也可以按「測試 Notion 授權」確認連線。

請勿將 Token 貼到聊天或公開場合。Token 預設只保留到 Chrome 完全關閉；若勾選「在這台電腦記住 Token」，下次就不用重新貼上，請只在自己的電腦上使用這個選項。

### 2. 選擇整理庫

**使用既有資料庫**

在 Notion 開啟要使用的資料庫，從右上角「⋯」→「Connections」加入剛才建立的 Integration。回到 Savour 設定頁，按「載入可用資料庫」，選擇資料庫後按「使用這個整理庫」。

空白資料庫也可以使用，Savour 會補上保存所需的欄位。若清單中找不到資料庫，可以展開「進階：手動貼上資料庫網址」。

**建立新的整理庫**

在 Notion 建立空白頁面並加入 Integration，將頁面網址貼到設定頁的「建立新的整理庫」，按「建立 Notion 整理庫」。

預設名稱為「留己看」，英文介面為「For Later Me」。

之後可以隨時更換整理庫。更換會重建本機的保存紀錄，不會刪除或修改兩個資料庫中的內容；仍有等待中的項目時，請先完成處理。

### 3. 選擇介面語言

介面支援正體中文與英文，預設跟隨瀏覽器語言，也可以在設定頁右上角按「中／EN」切換。

新整理庫的欄位名稱會跟隨建立時的介面語言，之後切換語言不會改動既有欄位名稱，你也可以自行重新命名。

## 使用方式

| 想做的事 | 怎麼做 |
|---|---|
| 保存目前頁面 | 按擴充功能的「保存目前頁面」、按 `Alt+S`，或使用右鍵選單 |
| 更新已保存的內容 | 開啟原文，按「更新 Notion 頁面」並確認 |
| 只保存一段文字 | 反白文字，從右鍵選單或擴充功能選擇「存成新頁面」 |
| 將文字加入既有頁面 | 反白文字，選擇「加到這篇的 Notion 頁面」或「加到其他頁面…」 |

「更新 Notion 頁面」只替換保存的原文，保留原文上下的筆記與加入的選取文字。串文若有缺段，也可以再次保存來補完。

加入既有頁面的選取文字會接在頁面最後，以分隔線隔開，不會取代原本內容。

「保存目前頁面」預設快捷鍵為 `Alt+S`；「保存選取的文字」可自行指派快捷鍵。兩者都能在 `chrome://extensions/shortcuts` 調整。

## Notion 頁面與欄位

所有來源都保存在同一個整理庫，以「來源」欄位區分。頁面保存原文內容，資料庫欄位記錄名稱、來源網址、作者、發布時間與保存時間等資訊；新頁面也會使用來源網站的圖示。

欄位名稱可以自行更改，但請保留欄位與原有類型。「擷取鍵」「貼文編號」「原文範圍」供工具辨識保存狀態與更新位置使用，請勿刪除或修改其內容。

這些內部欄位會在初次設定時於資料庫檢視中隱藏；若也想在頁面上隱藏，可在 Notion 的「屬性可見性」中設為「始終隱藏」。

## 保存紀錄與同步

擴充功能會顯示最近的保存結果，以及內容或圖片可能不完整的提醒。暫時失敗的項目可以手動重試，也可以匯出清單核對。

「最近紀錄」下方的「同步 Notion」會重新讀取整理庫，更新本機的保存狀態；例如在 Notion 刪除文章後，可先同步再重新保存。

「清除紀錄」只清空畫面上的最近紀錄，不會刪除 Notion 內容，也不會重設已保存狀態。

## 已知限制

- 只能保存你有權查看、頁面已載入的內容，不會繞過登入、付費牆或存取限制。好友限定、私人帳號或付費內容存進 Notion 後是你的私人副本，請勿外流，並尊重原作者與內容的使用範圍。
- 各網站的版面與改版可能影響辨識，保存結果不保證完整重現原頁面；內容不完整時，可以改用反白文字保存。
- 影片以嵌入、連結或封面呈現，不下載影片檔；YouTube 字幕與逐字稿目前不保存。
- 圖片保存會占用 Notion 工作區空間。無法取得、超過大小限制或下載逾時的圖片可能略過，請留意保存結果。
- Chrome 內建頁面、Chrome 線上應用程式商店與 PDF 檔案無法保存。

## 隱私與安全

Savour 是獨立的開源工具，與 Notion、Threads、噗浪、X、Instagram、Facebook、LinkedIn、YouTube 及其營運公司沒有關聯，各名稱與商標屬於其所有人。

Savour 沒有分析追蹤，內容由瀏覽器直接保存到你選擇的 Notion 整理庫。

需要 Node.js 18 以上版本。

```bash
npm install
npm test
npm run check
```
